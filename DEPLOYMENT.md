This deployment serves the frontend with sample content and browser-local bookings/admin edits. No database, application authentication, real file upload, scheduled publishing or email sending is connected. A live Mapbox token was not supplied, so the venue map uses its designed placeholder.

The official production domain has not been assigned or promoted. Future source deployments use `vercel deploy --target preview`; production promotion belongs to the launch owner after content and service integration are approved.
